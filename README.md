# depthvideo

1:1 复刻 https://www.depthvideo.com/ —— 浏览器端视频深度图提取工具。

## 本地提速

默认行为与原站完全一致（推理输入长边 518）。本地使用可选提速手段：

- **缩小推理输入**：URL 加 `?infer=392`（或控制台执行 `localStorage.setItem('dv.inferLongSide','392')` 后刷新）。推理输入长边从 518 降到 392，匹配导出帧率场景约 +70% 速度，深度细节略降；数值会偏离原站输出，验收对比时请关掉。
- **源帧去重**（内建，无需开关）：导出 fps 高于源视频 fps 时，重复源帧自动跳过重复推理，输出逐帧一致，最高 3× 提速。

其余优化（解码/推理流水线交叠、MessageChannel 让出、渲染快路径）默认生效，不改变输出。
